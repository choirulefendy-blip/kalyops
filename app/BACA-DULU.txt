KALY OPS 2.10 - CARA MEMASANG
============================

Folder ini (app/) adalah aplikasi Kaly Ops. Sejak 2.7 diterbitkan lewat GitHub Pages dari
repository GitHub choirulefendy-blip/kalyops, alamatnya: https://choirulefendy-blip.github.io/kalyops/
Aplikasi menyimpan semua data di database Supabase milik Anda.

1. Pasang database dulu (sekali saja)
   Ikuti README.md di paket kaly-ops-supabase.zip:
   - SQL Editor: jalankan kaly-ops-supabase.sql
   - SQL Editor: select public.kaly_setup_owner('emailanda@gmail.com', 'Nama Anda');
   - Authentication > Users > Add user: email yang sama, centang Auto Confirm User

2. js/config.js SUDAH DIISI
   Project URL dan anon key project zfrsznekongittxhuvej sudah terpasang.
   Tidak perlu diubah lagi. JANGAN ganti dengan service_role / secret key.

3. Terbitkan lewat GitHub Pages (sekali saja)
   GitHub > repository kalyops > Settings > Pages > Build and deployment > Source: GitHub Actions.
   Setiap perubahan di folder app/ pada branch main otomatis terbit dalam 1-2 menit
   (lihat tab Actions). Alamat: https://choirulefendy-blip.github.io/kalyops/

4. Masuk sebagai Owner (Kaly Backoffice)
   Owner / Manajer masuk lewat https://choirulefendy-blip.github.io/kalyops/backoffice/
   Pakai email dan kata sandi dari langkah 1. Tambahkan staf di Pengaturan,
   lalu buat akun login mereka di Supabase dengan email yang sama.

Tidak ada akun demo. Setiap staf masuk dengan email dan kata sandinya sendiri.

   MEMASANG SERVER NOTIFIKASI (sekali saja, oleh Owner)
   1. Jalankan SQL 2.4 (langkah a di atas). SQL ini juga menyalakan ekstensi pg_net.
   2. Supabase > Edge Functions > Deploy a new function > Via Editor.
      Nama fungsi: kaly-push. Hapus contoh kode, tempel isi file
      functions/kaly-push/index.ts dari paket kaly-ops-supabase.zip, lalu Deploy.
   3. Buka fungsi kaly-push > Details: MATIKAN "Verify JWT" (Enforce JWT verification), simpan.
      (Lewat Supabase CLI: supabase functions deploy kaly-push --no-verify-jwt)
   4. Kaly Ops > Pengaturan > Notifikasi di perangkat > Sambungkan.
   5. Di setiap HP/laptop: tombol speaker > Aktifkan notifikasi di perangkat ini > Kirim tes.
   Tidak perlu Firebase atau kunci tambahan. Kunci pengiriman (VAPID) dibuat otomatis.

   HP & BROWSER
   - Android: Chrome, Edge, Samsung Internet, Firefox. Laptop: Chrome, Edge, Firefox, Safari.
   - iPhone/iPad (iOS 16.4+): buka Kaly Ops di Safari > Bagikan > Tambah ke Layar Utama,
     lalu buka Kaly Ops dari ikon itu dan aktifkan notifikasi di sana.
   - Aplikasi Android Kaly Ops 1.2 (tablet kasir): notifikasi Android selama aplikasinya
     berjalan, termasuk saat kasir membuka aplikasi lain. Untuk HP pribadi Owner/Manajer,
     pakai Chrome agar notifikasi tetap masuk saat Kaly Ops ditutup.
   - Bila notifikasi tidak muncul: cek izin notifikasi browser/aplikasi, mode Jangan Ganggu,
     dan penghemat baterai (Android: Pengaturan > Aplikasi > Chrome > Baterai > Tidak dibatasi).
